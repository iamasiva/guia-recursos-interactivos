Guía de uso de la skill INTERACTIVO (Transformador)

Esta es la misma skill que usamos en IA Masiva para armar las guías interactivas que regalamos. Tú escribes el contenido en Word como siempre lo has hecho, y la inteligencia artificial se encarga de convertirlo en una página web con diseño propio, botones, campos y acciones dinámicas.

No necesitas saber programar, no necesitas instalar librerías y no necesitas pagar hosting. El resultado es un solo archivo que abres en el navegador o publicas con un link para compartir.

Lo que necesitas antes de empezar

  • Claude Code instalado en tu computador.
  • El archivo INTERACTIVO (Transformador).md, que es la skill.
  • Un documento de Word con el contenido de tu recurso.
  • Una cuenta de GitHub, solo si quieres publicarlo y compartir el link.

Los cuatro pasos

0 de 4
1

Crea la carpeta y el documento

Crea una carpeta nueva en tu computador. Dentro, guarda el documento de Word con el contenido de tu recurso. Esa carpeta va a ser el proyecto completo, así que mantenla limpia: el Word, la skill y nada más.

2

Pega la skill dentro de la carpeta

Copia el archivo INTERACTIVO (Transformador).md y pégalo en esa misma carpeta, al lado de tu Word. No hace falta crear subcarpetas ni cambiarle el nombre.

3

Llama la skill desde Claude Code

Abre Claude Code y selecciona la carpeta que acabas de crear como carpeta del proyecto. Escribe el símbolo de arroba: se despliega la lista de archivos que hay dentro. Selecciona la skill y escribe la instrucción indicando cuál es tu documento.

La frase que vas a escribir es esta:

@INTERACTIVO (Transformador).md ejecuta esta skill sobre el documento mi-guia.docx

Cambia mi-guia.docx por el nombre real de tu archivo. De ahí en adelante la skill trabaja sola: lee tu documento, entiende para quién es y qué busca lograr, elige un diseño, decide qué partes conviene volver interactivas y genera un archivo llamado index.html.

4

Publica y comparte

Ya puedes abrir el index.html haciendo doble clic. Si quieres un link para compartir, pídeselo a Claude Code en el mismo chat:

sube este proyecto a un repositorio nuevo de GitHub, activa GitHub Pages y pásame el link

Listo. Tienes un recurso publicado, con link propio y sin pagar hosting.

Qué interactividad puede aparecer

No hay una regla fija. La skill lee tu contenido y decide qué aporta de verdad. Estos son algunos de los patrones que suele encontrar:

Si tu contenido tiene…Puede convertirse en…
Una tabla que el lector debe llenar→Campos editables con totales que se calculan solos
Números que dependen de cada persona→Una calculadora o una gráfica que cambia en vivo
Prompts, plantillas o mensajes para reutilizar→Botones de copiar en un clic
Un texto con espacios en blanco→Campos que arman el texto final listo para copiar
Un proceso por pasos→Un checklist con progreso visible
Listas largas o comparaciones→Filtros o secciones desplegables

Si tu documento es puro texto narrativo y no hay nada que manipular, la skill no inventa botones por inventarlos. Te entrega una lectura limpia y bien diseñada, que también es un buen resultado.

Problemas comunes

Revisa que el archivo .md esté dentro de la carpeta que seleccionaste como proyecto en Claude Code. Si lo pegaste después de abrir la sesión, vuelve a escribir la arroba para que refresque la lista.

No necesitas volver a llamar la skill. Sigue en el mismo chat y pide el cambio con tus palabras: colores más sobrios, tipografía más grande, otro orden de secciones. Claude Code edita el index.html directamente.

Las imágenes van incrustadas dentro del HTML para que todo quede en un solo archivo. Si tu Word traía fotos pesadas, redúcelas antes de generar el recurso o pídele a Claude Code que las comprima.

Se puede. El index.html es un archivo estático común y corriente, así que funciona en cualquier hosting o dominio propio, no solo en GitHub Pages.
